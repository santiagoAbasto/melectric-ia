# ADR 0003 — Relaciones extraídas del catálogo nacen sin verificar

Decisión: «Relé térmico para DILM17 hasta DILM32» crea relaciones `AUTO_EXTRACTED` con la frase como evidencia. El
asistente cita la frase pero no afirma compatibilidad hasta que un ingeniero la verifica.
Motivo: es texto comercial del propio cliente (fuente válida) pero no una tabla de coordinación.
